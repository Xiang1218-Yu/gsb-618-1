# 债券发行与存续期合规管理平台 PRD

## 1. 产品概述
债券发行与存续期合规管理平台是面向债券承销商、发行人和受托管理人的一站式合规管理系统，覆盖债券从承销立项、发行注册到存续期管理的完整生命周期。平台通过自动化监控、智能预警和可视化追踪，帮助用户高效管理募集资金用途、财务指标和舆情动态，确保债券全流程合规运作。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 核心权限 |
|------|----------|
| 管理员 | 系统配置、用户管理、全部数据查看 |
| 项目经理 | 债券项目管理、承销流程操作 |
| 合规专员 | 合规审查、预警处理、报告生成 |
| 财务监控 | 财务指标监控、募集资金追踪 |

### 2.2 功能模块
1. **控制台首页**: 数据概览、待办事项、预警提醒、快捷入口
2. **承销发行管理**: 项目立项、尽职调查、材料申报、发行进度
3. **存续期管理**: 债券信息管理、付息兑付、信息披露
4. **募集资金追踪**: 资金到账、使用审批、流向监控、用途合规
5. **财务指标监控**: 指标配置、自动计算、阈值预警、趋势分析
6. **舆情动态监控**: 舆情抓取、情感分析、风险预警、事件追踪
7. **合规报告中心**: 定期报告、临时报告、合规检查、档案管理

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深蓝色系 (#1e3a5f) 代表专业、可信的金融行业属性
- **辅助色**: 金色/琥珀色 (#f59e0b) 作为强调色，绿色 (#10b981) 表示正常，红色 (#ef4444) 表示风险预警
- **按钮风格**: 圆角矩形，hover 状态有阴影过渡，主要按钮使用渐变底色
- **字体**: 使用系统默认中文字体栈，标题使用较粗字重，正文清晰易读
- **布局风格**: 左侧固定导航栏 + 顶部状态栏 + 主内容区，卡片式布局，数据可视化丰富
- **图标风格**: 使用 Lucide 线性图标，简洁专业

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 控制台首页 | 数据概览 | 网格布局卡片，大字号数字，图标标识，悬停微动效 |
| 控制台首页 | 预警面板 | 风险等级颜色区分，时间排序，一键处理按钮 |
| 承销发行管理 | 项目列表 | 表格布局，状态标签彩色标记，行内操作按钮 |
| 募集资金追踪 | 资金流向 | 桑基图/进度条可视化，流水列表可展开详情 |
| 财务指标监控 | 指标面板 | 仪表盘/数字卡片，趋势 sparkline 小图 |
| 舆情监控 | 舆情列表 | 卡片式布局，情感标签彩色圆点，来源图标 |
| 全局 | 导航栏 | 深色背景，白色文字，当前页面高亮，折叠展开 |

### 4.3 响应式设计
- 桌面优先设计，最小支持 1280px 宽度
- 侧边栏可折叠以适配中等屏幕
- 表格区域支持横向滚动
- 卡片布局在小屏幕自动调整为单列
